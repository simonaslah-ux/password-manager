# Slaptažodžių generatorius ir saugykla

Tai PHP OOP pagrindu kuriamas projektas, skirtas slaptažodžių generavimui ir saugojimui.

## Planuojamas funkcionalumas

- Vartotojų registracija
- Prisijungimas prie sistemos
- Slaptažodžių generavimas pagal pasirinktus parametrus
- Slaptažodžių saugojimas MySQL duomenų bazėje
- Slaptažodžių šifravimas AES metodu
